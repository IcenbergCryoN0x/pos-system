# Point of Sale System

A CodeIgniter 4 Point-of-Sale system using MySQL database integration.

## Features

- Landing page
- About page
- Customer Accounts page
- User Accounts page
- MySQL database
- CodeIgniter Models
- Query Builder with `findAll()`
- Navigation links between pages

## Routes

| Page | URL |
|---|---|
| Landing Page | `/` |
| About Page | `/about` |
| Customer Accounts | `/customers` |
| User Accounts | `/users` |
